# Security policy

## Reporting a vulnerability
Please **don't** open a public issue. Report it privately through GitHub instead: open the repository's
**Security** tab and choose **Report a vulnerability**. If that button isn't there, open a minimal issue that
asks for a private contact, without any details.

We aim to reply within 7 days, and we'll keep you updated until it's fixed.

## Scope
All repositories in the clariva-hq organisation. Fixes go to the latest `main` only.

## Never include
Secrets, API keys, tokens or personal data, in reports, issues, pull requests or commits. If you find a leaked
secret, report it privately so it can be revoked.
